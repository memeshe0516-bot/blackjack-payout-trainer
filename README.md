# ブラックジャック 3:2 配当トレーニング

ブラックジャックのナチュラル成立時に、ベット額の1.5倍を正しいチップ構成で配当する練習用ブラウザアプリです。

## 公開版

https://memeshe0516-bot.github.io/blackjack-payout-trainer/

## 特徴

- 初級・中級・上級・試験・苦手問題モード
- 横から見たチップの束表示
- 金額と最小枚数の二段階判定
- 端末内に学習記録を保存
- スマートフォン・PC対応

## ローカルで起動

```bash
npm install
npm run dev
```

## GitHub Pages

`main` ブランチへ更新すると、GitHub Actionsが自動でビルドしてGitHub Pagesへ公開します。リポジトリの **Settings → Pages → Build and deployment → Source** は **GitHub Actions** を選択してください。
