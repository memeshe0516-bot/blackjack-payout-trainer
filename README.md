# ブラックジャック実務トレーニング

ブラックジャックの3:2配当とインシュアランス処理を、実際のチップ表示で練習するブラウザアプリです。

## 特徴

- 初級・中級・上級・試験・苦手問題モード
- インシュアランスの条件判断・回収・2 to 1配当・おつり練習
- 横から見たチップの束表示
- 金額と最小枚数の二段階判定
- モードに応じた学習記録を端末内に保存
- スマートフォン・PC対応

## ローカルで起動

```bash
npm install
npm run dev
```

## GitHub Pages

`main` ブランチへ更新すると、GitHub Actionsが自動でビルドしてGitHub Pagesへ公開します。リポジトリの **Settings → Pages → Build and deployment → Source** は **GitHub Actions** を選択してください。
